# Mapeo de historias de usuario → implementación

Trazabilidad de cada historia de usuario (HU-01 a HU-15) con la pantalla, los endpoints y las pruebas que la cubren, y su **estado real** verificado el 19/11/2026 tras levantar el sistema desde cero (`docker compose down -v && docker compose up --build`).

> El texto de las HU se reconstruyó a partir de la Fase 2 porque el documento de la Fase 1 no estaba disponible (ver `docs/DECISIONES.md`). La prioridad MoSCoW sigue la Fase 2: 43 SP Must (HU-01 a HU-10), 18 SP Should (HU-11, 12, 13, 15) y 3 SP Could (HU-14).

**Abreviaturas de pruebas**
- **API**: Jest + Supertest contra MySQL real (`backend/tests/api/*.test.js`).
- **UNIT**: pruebas unitarias (`backend/tests/unit/*.test.js`, `frontend/src/**/*.spec.ts`).
- **PM**: colección Postman/Newman (`tests/postman/`), con el número de carpeta.
- **E2E**: Playwright en navegador (`tests/e2e/flujo-completo.mjs`).
